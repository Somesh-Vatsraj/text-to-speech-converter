# 🗣️ Text to Speech Converter

A simple, elegant, and fully responsive web application that converts text into speech using the **Web Speech API**. Built with pure **HTML, CSS, and JavaScript** – no external libraries required (except Font Awesome for icons).

## ✨ Features

- 🔊 **Speak Text** – Convert any written text into natural-sounding speech.
- 🎤 **Voice Selection** – Choose from all available system voices.
- ⏩ **Adjustable Rate** – Speed up or slow down the speech (0.5× to 2.0×).
- 🎵 **Adjustable Pitch** – Change the tone of the voice (0.5 to 2.0).
- ⏹️ **Stop / Clear** – Stop speaking instantly or clear the text area.
- ⌨️ **Keyboard Shortcut** – Press `Ctrl + Enter` (or `Cmd + Enter`) to speak quickly.
- 📱 **Fully Responsive** – Works smoothly on Desktop, Tablet, and Mobile.

## 🛠️ Technologies Used

- **HTML5** – Structure
- **CSS3** – Styling, Flexbox, Grid, and Media Queries
- **JavaScript (Vanilla ES6)** – Logic and Web Speech API integration
- **Font Awesome 6** – Icons for better UX
- **Web Speech API** – Browser-native speech synthesis
